# Aria Magic Voice for Android

Aria 安卓端原生输入法（基于 Android InputMethodService 开发），主打完全离线端侧高精准语音输入、九键与全拼智能键面、极致隐私保护。

## 规格与兼容性
- **系统要求**：Android 10.0 (API 29) 及以上（实机已深度兼容 Android 14 / Android 16 折叠屏）
- **CPU 架构**：`arm64-v8a` 原生高效运行
- **包体格式**：`.apk`（单包自适应手机与折叠屏/平板设备，无需区分安装包）
- **权限声明**：仅需要 `RECORD_AUDIO`（本地录音）与 `BIND_INPUT_METHOD`（系统输入法绑定），绝无通讯录、定位等越权申请

## 核心特性
1. **端侧本地语音模型**：离线实时语音转写，不依赖云端 API，无网络也能高速说话上屏。
2. **九键/全拼自适应双模式**：支持 9 键拼音、26 键全拼、中英自由混输与快捷短语。
3. **真实端侧诊断与链路闭环**：内置脱敏诊断引擎，支持一键发送环境诊断至中台服务。
