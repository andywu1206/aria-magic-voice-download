# Aria Magic Voice for iOS

Aria iOS 端输入法与语音转文本组件（基于 Apple Keyboard Extension 与 Whisper Kit 原生开发）。

## 规格与生态说明
- **系统要求**：iOS 17.0 或更高版本
- **设备支持**：iPhone 与 iPad 通用（Universal）自适应界面
- **正式分发通道**：Apple TestFlight 官方公测 / App Store 正式上线
- **特别说明**：由于 iOS 系统签名安全沙盒限制，本仓库不分发未经 Apple 签名的原始 `.ipa` 文件。请用户通过官方 TestFlight 邀请链接或 App Store 获得完整安装与自动更新服务。
