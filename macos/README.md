# Aria Magic Voice for macOS

Aria 桌面端原生输入法（基于 macOS InputMethodKit 开发），支持离线语音转文本、超级学习与快捷短语。

## 规格与要求
- **系统要求**：macOS 14.0 (Sonoma) 或更高版本
- **架构支持**：Apple Silicon (M1/M2/M3/M4 系列) 原生运行
- **包体格式**：`.dmg`（包含免拖拽自动安装器与真输入法包体）
- **安全认证**：Apple Developer ID 签名并经 Apple Notary Service 公证及 Staple

## 资产命名与 Tag 规范
- **Tag 规范**：`v90.xxx`（例：`v90.616`）
- **附件命名**：`AriaInputMethod-macOS-v<version>.dmg`
- **历史发布**：请前往本仓库的 [Releases 页面](https://github.com/andywu1206/aria-magic-voice-download/releases) 获取经过公证的安装镜像。
